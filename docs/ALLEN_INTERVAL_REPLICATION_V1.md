# 固定统一区间约束：新开发划分与稀疏时间复现 V1

预登记日期：2026-10-16；结果族 `results/allen_interval_replication_v1`。本轮按用户要求固定上一轮统一联合区间约束，不调整权重尺度、不加模块、不开展可靠性加权搜索。本协议先于正式新模型训练及新划分模型结果读取封存。

## 1. 研究问题与边界

上一轮 Allen–Cahn 统一约束相对 none 的平均场误差下降约 1.65%，但早期退步、收益偏向一个种子，且全频曲率指标仍更优。170 个实际可靠性权重全为 1，未形成有效机制差异。当前只检验固定统一约束是否在另一个开发划分、以及首末时刻监督下仍出现收益。

固定 PDE `u_t=.01u_xx+5u(1-u²)`、长度 2、时间 `[0,.5]`，固定原周期单坐标 FNO（16 宽、16 模式、4 层、34,209 实参数）。不声称新架构或新积分公式，不增加 Transformer/CNN/branch/trunk，也不额外训练 Burgers。

仍然缺少同周期编码、同预算的点态 PDE 损失对照，所以不声称优于 PINN／自动微分点态物理约束。已有积分研究及上一轮失败筛查保持原记录；本轮是开发复现，不是确认成功。

## 2. 一个固定重划分，不接触预留集

唯一案例池是已经使用过的 IDs `200000..200299`。用 `np.random.default_rng(2026101601).permutation` 得到 300 个 ID 的排列，先取前 100 个为训练、后 200 个为开发，再分别排序；不可先排序整个排列再取前缀。完整 ID 列表及与旧划分的重叠数量写入封存计划。

从六份既有完整缓存按 ID 重排，不生成任何新轨迹，不调用求解器；缓存缺失或身份／SHA 不符直接失败。训练和开发必须互斥，合并严格等于原 300 个案例；禁止访问 `200300+` 预留案例。

新开发集含部分旧训练案例，因此所有新 warm 必须从头训练，不能载入旧模型、优化器、训练尺度或统计量。重划已经消费过的案例仍是开发证据，不是新的独立数据集，也不是未见确认。旧模型、缓存及结果全部保留。

## 3. 两种监督、三组约束、三个种子

| 条件 | 实际传入训练的时刻 | 开发主指标 |
|---|---|---|
| dense | `[0,.05,.125,.25,.5]` | 200 案例四个非初始时刻 |
| sparse | `[0,.5]` | 200 案例三个未监督中间时刻 `[.05,.125,.25]` |

每条件种子 0、1、2，各自从头 warm1500 步，再从完整 warm 分叉 none、全频曲率 full、统一联合积分 interval_uniform，各续训 750 步。合计 6 个 warm＋18 个续训＝24 次训练记录，22,500 个新优化步；warm 成本只计一次，不重复计入三个分叉。

每个种子在两条件的初始张量、样本顺序及随机流匹配；不同种子初始张量不同。稠密／稀疏 warm 训练后的模型不同是预期，不要求它们相同。三个分叉在同条件同种子共享自己的 warm 模型、优化器和 RNG。

保持原设置：B16、AdamW、weight decay .0001；warm1500 步学习率 `.001→.00001`，续训750 步 `.0003→.00001`，原 cosine 规则。约束／数据初始梯度范数比例固定 `.3`，仅使用该条件已监督训练数据、同一个首16训练探针，随后冻结。最终2250总步模型，不做早停、种子选择、checkpoint选择或超参数搜索。

## 4. 稀疏条件的防泄漏要求

旧物理缓存包含全部五帧，会被加载以核验身份及重排；不伪称这些字节未读。关键是先选择观察时刻，再计算所有拟合数据和统计量：

- 稀疏 `train_y` 只含两帧，`times` 只含 `[0,.5]`；不把完整训练轨迹交给训练核心。
- 输入均值／标准差来自新训练初始场；目标标准差、归一化目标、带分母保护的逐样本数据权重和梯度校准只使用实际观察训练标签。
- 不使用未观察训练中间帧估计尺度、可靠性、损失权重或噪声。无额外16训练案例高精度求解、无可靠性图、无 tau。
- 开发五帧只作固定步数日志和最终评价，不用于优化、校准、调参、早停或选模。
- 保存观察列、选定目标和归一化数据的 hash 证明。单元测试污染未观察训练标签／开发真值，验证训练数据与统计不变；另做端到端稀疏训练／校准张量一致性检查。

固定的是损失公式及校准规则，不是旧稠密数据估计出的数值尺度。若为了“固定尺度”复用旧五时刻目标标准差，反而会向稀疏实验泄漏未观察信息。

## 5. 原统一区间约束，不改窗口或尺度规则

直接复用封存的 `joint_interval_residual`：

`r_k = (T/sigma_observed_train) * [(u_hat_k(c+h)-u_hat_k(c-h))/(2h) - Simpson5_average(F_hat_k(u_theta))]`。

`T=.5`，模式0–16，4倍FFT去混叠 Allen 三次项；DC 单计、正频率双计的平方系数能量。两端及 RHS 都属于同一可训练预测，不使用中间真值标签或冻结的 oracle 时间导数。

仍用旧随机查询 `q~Uniform(.05,.5)`，`a=(q-.05)/.45`；半宽 `.005/.01` 按批内槽位交替，中心 `c=h+(.5-2h)*a`。Simpson5 权重 `[1,4,2,4,1]/12` 计算 RHS 区间平均。不要根据本轮结果改频带、窗口、半宽、强度或时间分布。

所有续训组计算相同约束前向，仅选定目标反传；相同优化步数不等于相同 FLOPs。全频曲率严格复用原算式和 Nyquist 计数，不重写旧核心。

## 6. 评价、描述性复现标记与反例

在每条件内报告相对 none 的全部三个种子主场指标及配对变化，主指标使用上表预定列。dense 的四时刻主指标与 sparse 的三时刻主指标不同，不能直接比较二者数值或改善百分比来宣称“稀疏监督更有价值”。

因此两条件都额外报告完全相同的三个中间时刻和四个未来时刻，使用同一 200 开发案例、同一逐样本相对误差定义。稀疏价值交互仅在共同三中间时刻计算：`gain_sparse - gain_dense`，其中每个 gain 为同条件 uniform 相对 none 的均值相对下降，附三种子配对差。它是描述，不是显著性、因果或独立数据验证。

预先规定较强方向性复现标记：同条件 uniform 相对 none 的主场均值相对下降至少 1%，且三个种子主场误差均下降。1% 是受上一轮观察启发的任意描述性标记，不是统计显著性或已证明的应用意义；不满足也完整报告，不修改阈值，不因此追加调参。

同时报告全网格梯度／曲率、共同中间时刻结构指标、全部五时刻场误差（IC、最早时刻、末时刻均保留）、强 full 曲率的权衡以及反例。不能用场均值代替结构指标，也不能把固定强度比较称为充分调参最优。无新的中间时刻数值真值、局部修正输出或胜出模型导出。

## 7. 恢复、审计与成本

训练核心不改；每50步原子保存模型、优化器、阶段步数、所有 RNG、collocation RNG、批次／查询 hash 和历史，每250步落盘固定评价。测试覆盖两条件、三续训目标 CPU/CUDA 精确中断恢复及未观察标签污染不变性。单写进程；进程仍在休眠时不能另启重复 worker。

独立审计要求全部24个记录通过 source／数据来源／ID／归一化／warm血缘、优化器步数、初始化、随机流、校准及200案例预测重放；跨条件核验共同初始化与流，条件内核验三分叉。因为训练 ID 已改变，不冒充新模型应该与旧历史最终张量相同。

分列6个warm和18续训的计时优化步成本；不含评价／校准等的 step wall time 不叫端到端流程时间。显存只称最后运行段 peak allocated，不称跨恢复总峰值。推理统一 batch16×5times×256，预热3次、20次CUDA同步计时；同架构之间的小波动不解释为速度提升。没有参考求解和权重图成本，不隐瞒 warm 新训成本。

## 8. 结论范围

本轮只有一个重划开发集、三种模型种子和单个转移强度；旧300案例重复使用和重叠不构成新的独立确认。不能声称少样本数量、噪声、跨分辨率、跨 PDE 或可靠性加权成功。暂不打开预留确认集；后续必须另行锁定规则和比较标准后再获得相应授权。
