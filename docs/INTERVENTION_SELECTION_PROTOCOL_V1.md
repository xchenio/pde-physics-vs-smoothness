## 1. 研究问题

> 在固定总预算下，**仅使用训练/验证期可见的信息**，能否提前判断该改善表示、
> 稳定优化、还是增加数据/正则，并选到**真的有效**的干预？

这是把"案例分析"升级为"方法"的唯一路径。若规则在未见设置上没有样本外选择价值，
就诚实写成负结果，不为凑方法继续加复杂损失或堆模块。

## 2. 预算与记账

- 总预算 `C` 以**训练步数**计（`steps × batch_size` 折算为等效样本数），
  诊断与选择的开销一律计入预算：
  - 诊断成本：算 LB 需要一次前向传播（所有训练样本）→ 折算 1 个 epoch；
  - 选择成本：若策略要用"验证集搜索"，跑的每个候选干预的短训练都全额计入；
  - 干预训练成本：剩余预算全部用于最终干预的训练。
- 默认 `C = 6000` 步（与项目既有 sweep 一致）。

## 3. 干预集合 𝓘（冻结）

| ID | 干预 | 类别 | 预算消耗 |
|---|---|---|---|
| I0 | 什么都不做（沿用默认） | — | 0 |
| I1 | 换 Fourier / 随机特征 trunk（或 FNO 的 modes 加倍） | 表示 | 0（只改架构） |
| I2 | 宽度加倍 | 表示 | 0（参数变多，步数预算不变） |
| I3 | 训练步数加倍 | 优化 | 全额剩余预算 |
| I5 | 平滑/权重正则（权重衰减 1e-3） | 泛化 | 0 |

**修订记录（实现约束，在跑任何结果之前记录）**：初稿中的 I4（训练样本数加倍）
从 𝓘 中移除。原因：本协议的所有测试设置共用同一份 1000/200/200 划分，
"加倍训练数据"会改变划分定义从而破坏跨设置可比性；而本轮预算只约束步数，
数据预算不是变量。因此 𝓘 = {I0, I1, I2, I3, I5}。
这不触及阈值、规则与评估口径，故仍记为 V1。

说明：I1/I2 是零预算成本，因此"默认基线"必须定义清楚——
本协议的默认（I0）是 **width=64 的 MLP trunk / width=32 的 FNO、1500 步**，
与 `public_fixed_t1_v1` 的既有设置一致。

## 4. 诊断特征与规则（冻结）

只用 train/val 可见的信息，三个归一化比值（都用训练误差做分母）：

```
r_lb  = LB_train / train_rel
r_opt = (train_rel - LB_train) / train_rel          # = opt_gap/train_rel
r_gen = (val_rel - train_rel) / train_rel
```

**规则 R（冻结，阈值来自 V1 的独立观测，不是在本实验上调出来的）**：

```
if   r_opt >= 0.30            -> 优化侧：I3（步数加倍）
elif r_lb  >= 0.40            -> 表示侧：I1（换 Fourier/加 modes）；若已是 Fourier 则 I2
elif r_gen >= 0.15            -> 泛化侧：I5（正则）；若样本可增加则 I4
else                          -> I0
```

阈值来源（**V1 已发表的观测**，见 `READOUT_ATTRIBUTION_V1.md` §3）：

| 架构 | r_opt | r_lb | r_gen |
|---|---|---|---|
| deeponet_fourier | 0.855 | 0.135 | 0.150 |
| deeponet_mlp | 0.503 | 0.490 | 0.044 |
| fno | 0.037 | 0.716 | 0.281 |

阈值取在三类之间的空隙上：0.30（分开 0.037 与 0.503/0.855）、
0.40（分开 0.135 与 0.490/0.716）、0.15（分开 0.044 与 0.150/0.281）。
⚠️ 这是**用 V1 的观测定的先验**，不是本实验的调参结果；
若后续发现阈值明显不合适，只能在 V2 里改，并把 V1 的结果作废重评。

## 5. 对照三方（冻结）

对每个测试设置，跑 4 种策略并比较最终 test 相对误差：

| 策略 | 做法 |
|---|---|
| **S-RULE** | 按 §4 规则选干预 |
| **S-FIX** | 固定选 I3（步数加倍），最常见的"默认调参" |
| **S-RAND** | 在 𝓘 上均匀随机选（固定 seed，每个设置 3 次取均值） |
| **S-VAL** | 预算内验证集搜索：把预算平分给 3 个候选（I1/I3/I5）各跑 1/3 步，选 val 最好的再全预算重训 |

评估指标（每个设置）：
1. **相对收益**：`(test(I0) - test(selected)) / test(I0)`；
2. **错误选择率**：选中的干预反而比 I0 差的比例；
3. **净收益**：扣除该策略自身消耗的预算后的收益。

## 8. 预登记的失败标准

以下任一成立即判为**失败**，按负结果如实写入论文，不追加修补：

1. S-RULE 的平均相对收益**不显著优于** S-RAND（配对 bootstrap，5 个设置）；
2. S-RULE 不优于 S-VAL（说明"看验证集直接搜"更划算，诊断没有增量价值）；
3. 错误选择率 > 1/3。

## 9. 明确不做的事

- 不在测试设置上回头调阈值（那是过拟合，不是方法）；
- 不把 T1 的校准结果算进未见设置的统计；
- 不因为某个设置效果差就临时新增干预或改预算定义。
