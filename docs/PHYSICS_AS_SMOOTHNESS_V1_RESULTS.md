# D5：物理损失何时退化为平滑正则 —— H2/H3 结果（2026-10-16）

> 协议：`docs/PHYSICS_AS_SMOOTHNESS_V1.md`（实验前冻结）。
> 本轮覆盖 **H2（分辨率）** 与 **H3（样本量）**；H1（跨粘度 ν）需要 Nu0.01/Nu0.1 数据，尚未下载，未做。

## 1. 判定结果：H2 与 H3 都被证伪

判据（协议 §3）：`PDE − best_smoothness` 的配对 bootstrap（按 seed 配对，10k 次，
Bonferroni α = 0.05/5），要求增益 > 1% **且** 校正后区间**下界** > 0。

| 条件 | 选出强度 | PDE | gradient | curvature | PDE − best_smoothness | 判定 |
|---|---|---:|---:|---:|---:|---|
| H2 res=256 (stride 4) | 0.03 | 0.2054 | 0.2167 | **0.2050** | −0.0015 [−0.0128, +0.0086] | **不成立** |
| H2 res=128 (stride 8) | 0.03 | 0.2054 | 0.2161 | **0.2054** | −0.0001 [−0.0115, +0.0092] | **不成立** |
| H3 n=20 | 0.3 | 0.5135 | **0.4493** | 0.4798 | −0.1431 [−0.1866, −0.0891] | **不成立（显著更差）** |
| H3 n=50 | 0.3 | 0.4166 | 0.3873 | **0.3781** | −0.1048 [−0.1451, −0.0255] | **不成立（显著更差）** |
| H3 n=100 | 0.3 | 0.3560 | 0.3517 | **0.3364** | −0.0587 [−0.0780, −0.0220] | **不成立（显著更差）** |

**H2（H2 假设：欠分辨尺度下 PDE 会有独特增益）不成立**：
在两个分辨率上 PDE 与曲率平滑的差异都在 0 附近、区间跨 0，
即"降低分辨率"并没有让 PDE 变得比平滑正则更有信息。

**H3（H3 假设：数据越少 PDE 增益越大）不成立，而且是反向的**：
数据稀缺时 PDE 不但没有独特增益，反而**显著劣于**平滑正则
（n=20 差 14.3%，n=50 差 10.5%，n=100 差 5.9%）。
按协议，这就是负结果，不换强度、不换频段重试。

## 2. 但有一个重要的正面结论：PDE 确实优于"无惩罚"

把两个不同的问题分开：**"物理是否有用"** vs **"物理是否优于平滑正则"**。

| 条件 | PDE | 无惩罚 | PDE − none（校正区间） |
|---|---:|---:|---:|
| H2 res=256 | 0.2054 | 0.2083 | +1.4% |
| H3 n=20 | 0.5135 | 0.5284 | **+2.85%** [+0.47%, +6.55%] |
| H3 n=50 | 0.4166 | 0.4960 | **+16.0%** [+14.9%, +17.5%] |
| H3 n=100 | 0.3560 | 0.4230 | 显著为正 |

物理残差相对"什么都不加"是**真实有效**的，在中等数据量（n=50）上收益最大（+16%）。
但它带来的收益**不超过**一个同样强度、同样频段的曲率/梯度平滑正则。

⇒ 对这些条件，"PDE 残差退化为一个平滑正则"这一说法得到**支持**，
且被外推到了新的条件（不同分辨率、不同样本量）。

## 3. 两个必须记录的实现教训（否则会导出错误结论）

1. **绝对惩罚强度不可跨设置比较。** 初版直接沿用 0.03/0.1/0.3 作为 λ，
   在 n=1000 上 physics 0.03 就把误差从 0.206 恶化到 0.229——那是"惩罚太强"，
   不是"物理没用"。改为**梯度校准**：选 λ 使 ‖λ·∇penalty‖ = ratio·‖∇data‖，
   这里的 ratio 才是报告里的"强度"。
2. **PDE 惩罚有"平凡解吸引子"。** 最后一层零初始化使模型初始输出恒为 0，
   而 **u ≡ 0 恰好满足 Burgers**，残差在该点附近极其平坦 ⇒ 惩罚梯度 → 0
   ⇒ λ = ratio·‖∇data‖/‖∇penalty‖ 爆炸 ⇒ 解被彻底压成零场
   （实测 test rel L2 = 1.000）。因此必须先跑 50 步纯数据损失再校准并加惩罚。
   这条机制本身就值得写进论文：它解释了为什么 PI 类模型在某些设置下会整体崩溃，
   而不只是"精度差一点"。

## 4. 局限

1. **只有 Burgers、只有 ν=0.001**。H1（跨 ν 外推）是三条假设里最有可能
   成立的（平滑正则无法编码 ν 依赖的耗散），尚未测试。
2. 时间导数用的是两个时刻的有限差分 `u_t ≈ (u(t₂)−u(t₁))/Δt`，
   不是 autograd 的 ∂u/∂t；Δt 较粗（t=100 → 150）。
3. 只有 3 seed/条件，配对 bootstrap 的点数很少（3 对），区间偏宽。
4. 强度网格 0.03/0.1/0.3 在 H2 上全部选中 0.03（最小值），
   说明**更弱**的强度可能还有空间；协议禁止为此重跑，但应记为"网格边界未闭合"。
