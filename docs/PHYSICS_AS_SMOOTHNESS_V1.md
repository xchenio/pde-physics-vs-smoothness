# D5：物理损失何时退化为平滑正则（预登记，2026-10-16）

> 对应 `PUBLICATION_STRATEGY_20261016.md` 的 **D5**。
> 本文在跑任何新实验之前冻结判定口径；已有证据只做汇总引用，不做二次解读。

## 1. 已有证据（已封存、已消耗确认集，勿重述为"待验证"）

来源：`docs/FNO_REGULARIZATION_V1_RESULTS.md`（封存 4d60f18，500 条全新确认轨迹，
10k 配对 bootstrap，Bonferroni 5，最小 1% 增益门槛）。

| 冻结族 | 确认集相对 L2 | 相对无惩罚的增益 |
|---|---:|---:|
| 无惩罚 | 0.290253 | — |
| 已分辨 PDE 残差 | 0.286260 | 1.376% |
| 已分辨梯度平滑 | 0.286076 | 1.439% |
| 已分辨曲率平滑 | 0.282820 | 2.561% |

| 登记对比 | 均值差 | 校正后配对区间 | 结论 |
|---|---:|---|---|
| PDE − 梯度 | +0.000184 | [-0.000086, +0.000440] | **不可区分** |
| PDE − 曲率 | +0.003440 | [+0.002879, +0.004032] | **PDE 显著更差** |

另有 `docs/EXPERIMENT_LEDGER.md` 中 PHYSICS_STRESS_V1 的三组（Burgers sparse / noisy dense /
noisy sparse）与 Allen-Cahn，结论一致：曲率平滑全部不劣于 PDE。

**已经可以主张的**：在**已分辨网格、同分布、固定时刻**的条件下，
PDE 残差惩罚相对于匹配的平滑正则**没有独特增益**。
这不是"物理没用"，而是"在这个条件下它退化成了平滑正则"。

**还不能主张的**：任何关于"何时才有独特增益"的说法——现有实验没有覆盖
跨参数、跨分辨率、外推时刻这些维度。

## 2. 把问题精化为可检验的"何时"

物理残差与平滑正则的区别在于：平滑正则只约束**解的粗糙度**，
PDE 残差还约束**解与动力学的一致性**。因此预期 PDE 产生独特增益的条件是
"粗糙度信息不足以确定解"的情形。预登记三条假设：

| 假设 | 条件 | 预期 |
|---|---|---|
| H1 | **跨 PDE 参数外推**（训练 ν=0.001，测试 ν=0.01 / 0.1） | 平滑正则只能沿用训练分布的光滑度，PDE 编码了 ν 依赖的耗散 → PDE 有独特增益 |
| H2 | **低分辨率 / 欠分辨尺度**（stride 8 → 32，或训练在低分辨率、测试在高分辨率） | 已分辨残差失去信息；若 PDE 仍在原尺度上算，它的优势会消失甚至变负 |
| H3 | **数据稀缺**（n_train = 20 / 50 / 100） | 数据越少，先验越重要 → PDE 增益随样本数**单调下降**时增大 |

每条假设的**证伪条件**都预先写死：若 PDE − 最佳平滑的配对 bootstrap 区间上界 ≥ 0，
则该假设不成立，直接记为负结果，不加惩罚强度、不换频段重试。

## 3. 实验网格（冻结）

- 模型：沿用 FNO_REGULARIZATION_V1 的 34209 参数 FNO 与"1500 步数据预热 + 750 步续训"配方
  （保持与已有证据可比）。
- 惩罚：none / PDE / gradient / curvature，强度网格 0.03 / 0.1 / 0.3（沿用），
  频段固定 0..16（沿用），**不重新搜强度**（避免"调参调到赢"）。
- 条件：
  - A：ν 外推（需要 PDEBench Nu0.01 / Nu0.1 数据）
  - B：分辨率（stride 4 / 8 / 16，无需新数据）
  - C：样本量（20 / 50 / 100，无需新数据）
- 每个条件 3 seed；评估用**同条件内的独立留出轨迹**（不是已消耗的确认集）。
- 主判据：`PDE − best_smoothness` 的配对 bootstrap（10k，Bonferroni 校正），
  门槛 1% 且上界 < 0。

不需要新数据即可开跑的：**B 与 C**。需要下载的：**A**。

## 5. 论文定位与风险

- 定位：这是一篇**独立的负面/条件性结果**论文——
  "physics-informed losses are not uniquely informative when the grid is resolved and
  the test distribution matches"，并给出退化发生的**边界条件**。
- 与 arXiv:2601.11428（TMLR 的算子失败模式诊断）同类，且更聚焦一个具体机制。
- **风险**：如果 H1 也不成立（即所有条件下 PDE 都无独特增益），
  结论会更强但更"得罪人"——这会提高被拒概率，但按项目惯例**如实写**。
- 与 D4 的关系：D4 的规则会用到"是否该加物理损失"这一干预分支，
  因此 D5 的条件结论可以直接喂给 D4 的规则（作为 I5 的触发条件）。

## 6. 明确不做

- 不为"让 PDE 赢"去调惩罚强度或频段（那是过拟合）；
- 不把开发集上挑出来的最优强度当作结论（已有记录显示所选强度都在搜索边界上）；
- 不把已消耗的 500 条确认集再用作评估集。
